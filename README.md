# 필름캠 (FilmCam)

부드럽고 따뜻한 감성 색감 실시간 카메라 필터 앱 (Android).

## 기능
- 실시간 필터 미리보기 (OpenGL 셰이더) — 보이는 그대로 저장
- 필터 14종: 원본, 버터, 크림, 허니, 빈티지, 레트로필름, 골든아워, 피치, 로즈, 민트데이, 블루아워, 로모, 세피아, 소프트모노
- 필터 강도 슬라이더 + 조절 슬라이더 9개 (밝기·대비·채도·온도·틴트·페이드·글로우·그레인·비네팅)
- 미리보기 화면을 길게 누르면 원본과 비교
- 전·후면 카메라 전환, 갤러리(Pictures/FilmCam)에 저장

## 폰에서 설치하기 (GitHub Actions 자동 빌드)
1. 이 프로젝트를 GitHub 저장소에 올리면 자동으로 빌드가 시작돼요. (Actions 탭 → Build APK)
2. 빌드가 끝나면 저장소의 **Releases**에 `FilmCam.apk`가 올라와요.
3. 폰 브라우저에서 APK를 내려받아 설치 (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요).

## 필터 색감 바꾸기
`app/src/main/java/com/filmcam/app/FilterParams.kt` 의 `FilterPresets` 에서 숫자만 바꾸면 돼요.
새 필터는 `FilterPreset(...)` 한 줄 추가하면 목록에 나타나요.

## 요구 사항
Android 10 (API 29) 이상
